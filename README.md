## 1. 処理の流れ

本プログラムは、ZIPファイル内のCSVファイルをExcel（XLSX）形式に変換するプログラムです。

**処理手順**

1. ZIPファイルをアップロード
2. ZIPファイル内のCSVファイルを検索
3. CSVファイルをXLSX形式に変換
4. 変換したファイルを保存

### 2.1. ファイルのアップロード

- 変換するZIPファイルを選択します。
- 選択したファイルをアップロードして、変換を実行します。
- アップロードできるファイルはZIP形式のみです。

### 2.2. 変換結果

ZIPファイル内のCSVファイルを検索し、XLSX形式に変換します。

- CSVファイルが存在しない場合、該当するファイルはスキップされます。
- ファイル名が重複している場合、該当するファイルはスキップされます。
- その他の処理可能なファイルは、引き続き変換されます。

## 3. 実行方法

1. プログラムを起動します。
2. Webブラウザを開き、以下のURLにアクセスします。

   http://localhost:8080

3. 変換するZIPファイルをアップロードします。
4. 変換処理が完了したら、保存されたXLSXファイルを確認します。

## 4. その他

### 4.1. 対応ファイル形式

| 項目 | 対応形式 |
|---|---|
| アップロードファイル | ZIP |
| 変換対象ファイル | CSV |
| 変換後ファイル | XLSX |
| 対応エンコーディング | UTF-8 |
